# DDD2Self: Self-Supervised Image Denoising with Dynamic Data-driven Dropout

Official repository for the paper:

**DDD2Self: Self-Supervised Image Denoising with Dynamic Data-driven Dropout**  
Md. Tauhid Bin Iqbal*, Jubyrea*, Imon SA, Nahar N, Bae SH  
Published in IEEE Access, 2025

## Overview

Image denoising methods generally rely on large clean-noisy paired datasets for supervised training. However, obtaining clean target images is difficult and expensive in many real-world applications such as medical imaging, hyperspectral imaging, surveillance, and scientific imaging.

DDD2Self proposes a self-supervised denoising framework that learns directly from noisy observations without requiring clean target images. The proposed method introduces a **Dynamic Data-driven Dropout (DDD)** strategy that adaptively modifies the training process based on image characteristics, improving generalization and denoising performance.

## Key Contributions

- Self-supervised image denoising without clean paired datasets
- Dynamic data-driven dropout mechanism
- Improved robustness and generalization
- Effective learning under limited-data settings
- Applicable to domain-specific noisy imaging problems

## Method Overview

The proposed framework dynamically adjusts dropout behavior during training using image-driven characteristics. Unlike fixed masking or static dropout approaches, the method adapts according to local image structures and noise patterns, enabling more effective self-supervised learning.

## Applications

- Medical image denoising
- Hyperspectral image restoration
- Scientific imaging
- Surveillance imaging
- Low-light image enhancement
